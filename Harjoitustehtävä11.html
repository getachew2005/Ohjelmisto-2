Visual Studeo Code

Visual Studeo Code eli VSC on tietokone-sovellus, jossa pystytään ohjelmoimaan.

Sovelluksessa olevat tunnetut dokumenttitiedostot ovat esimerkiksi python-, html- ja CSS-dokumentti.

Visual Studeo Coden kautta pystytään julkaisemaan tietoja github.com-sivustoon, jossa opettajat pystyvät tarkistamaan oppilaiden tehtävien malliratkaisuja ja projekteja.
